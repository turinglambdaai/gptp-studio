Automotive Ethernet timing

One Linux workstation. Full gPTP visibility.

gPTP Studio is a professional IEEE 802.1AS / AUTOSAR EthTSyn debugging workstation built around the Linux timing stack: PHC, hardware timestamping, SO_TIMESTAMPING, linuxptp and explicit privilege control.

What it replaces

The timing debug bench, in one window.

GrandMaster / Slave / Listener

Switch roles with generated ptp4l configuration and supervised engine lifecycle.

PHC & hardware timestamp qualification

Inspect NIC driver, link, HW TX/RX timestamp support, /dev/ptpN and privilege readiness before a real engine starts.

Live sync analysis

Track offsetFromMaster, meanPathDelay, port state, GM identity and timing alarms in real time.

Packet-level correlation

Decode Sync, Follow_Up, Announce, PDelay_* and Signalling, with exact timestamp metadata and hex inspection.

Headless Doctor

Generate a redacted support report with NIC, PHC, linuxptp, privilege and per-role readiness facts.

Offline simulator

Exercise the same encode/decode/store pipeline without requiring target hardware.

Platform contract

Linux is not a port. It is the product.

Other operating systems are intentionally unsupported. A reduced-function port without the same PHC, hardware timestamp and linuxptp path would weaken validation and supportability.

Install

Start with Doctor.

Debian / Ubuntu

sudo apt install ./gPTP-Studio-v1.0.0-linux-amd64.deb
gptp-studio --doctor
gptp-studio

The package declares runtime dependencies and installs the desktop entry, icon and license notices. It does not silently grant Linux capabilities.

Relocatable tarball

tar -xzf gPTP-Studio-v1.0.0-linux-x64.tar.gz
cd gptp-studio-distributed
./bin/gptp-studio --doctor
./bin/gptp-studio

Useful for lab hosts where you want the application payload separated from the system package database.
