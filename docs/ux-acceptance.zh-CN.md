## 当前界面与职责

产品只面向 Linux，采用 Rivet/GTK4 原生宿主。当前六页是 Engine、Qualification、
Packets、Logs、GM Tuning、License & Reports。系统原生包基线为 ACCEPTANCE 中的
Ubuntu 24.04 / GTK >= 4.10；AppImage 需单独证明宿主兼容，附带依赖不等于所有旧发行版都受支持。
不再沿用旧 WebKitGTK 页面、构建命令或未验证的 Ctrl+1…6 绑定。

主任务是选择模拟/真实目标与网卡、查看资格、明确启动会话、观察时序/报文、停止所属任务并导出证据。
初始角色是被动监听。共享后端负责协议与 preflight 规则，宿主负责原生输入、焦点、辅助功能与真实状态呈现。

## 统一场景契约

| 初始状态 / 动作 | 必需的可见结果与恢复 |
| --- | --- |
| 全新包启动模拟器 | 模式与被动角色可辨认；进入可用状态或给出可操作错误，不隐式启动真实时钟角色进程。 |
| 选择真实模式 / 网卡 / 角色 | 区分选择目标、实际运行会话和资格结果，待提交配置不能显示为已生效。 |
| 启动被拒 | 说明失败条件与下一诊断动作，保留已运行的健康会话；READY 只是能力检测，不是精度校准。 |
| 会话运行 | 曲线、报文与日志标识来源，模拟轨迹不能标成真实网卡证据。 |
| 停止引擎 / 抓包 | 分别展示结果与仍在运行的所属进程；未实现并验证前不能将其中一个操作称作停止全部。 |
| 选择 / 过滤 / 查看报文 | 选择与详情指向同一报文；定义原生键盘操作和焦点返回；刷新时保留选择或解释失效。 |
| 导出 / 权限失败 | 原始抓包导出、Wireshark 留存回放免费；付费报告遵循当前 PRICING。取消/失败不能宣告完成或留下误导的最终文件。 |
| 切换语言 / 调整窗口与文字 | 主页名、模式/角色、状态/错误与恢复动作可用；语义一致不要求固定字号或像素。 |

使用已有控件名和原生激活方式。新增快捷键、焦点规则或状态呈现，在实现并通过原生输入验证前仍是目标；
不得虚构 automation ID 或用 CLI 输出代替 GUI 交互。

## 必须记录的证据

- [ ] 源码/依赖 SHA、包摘要/格式、发行版、架构、GTK、显示后端、语言与缩放。
- [ ] 临时数据下，全新包完成模拟器启动→输入→结果→停止→导出，附原生辅助功能与键盘证据。
- [ ] 缺依赖、启动失败、拒绝启动、导出失败与恢复；保留用户上下文和现有健康会话。
- [ ] 声明支持窗口/大文字下的键盘可达、名称/角色、焦点返回与可读性；实际产物的新截图。
- [ ] 免费导出、报告拒绝/凭据导入/恢复符合当前政策；更新资格使用已认证发行时间，不能换成当前日期判断。

物理 NIC/PHC、硬件时间戳、真实权限、参考时钟与时序精度需另有[硬件验收](hardware-qualification.md)
及[真实引擎配置](linux-real-engine-setup.md)证据。真实时钟角色变更只在明确选定的测试环境执行；
模拟器、构建、排队、跳过或未执行均不算上述实机结果。
