What it replaces

The timing debug bench, in one window.

GM / Slave / Boundary Clock / Listener

Switch roles with generated ptp4l configuration and supervised engine lifecycle.

PHC & hardware timestamp qualification

Inspect NIC driver, link, HW timestamps, PHC and privileges before a real engine starts.

Live sync analysis & root cause

Track offsetFromMaster, meanPathDelay, port state, GM identity and alarms; correlate jumps with packet evidence.

Packet-level correlation

Decode gPTP traffic with exact timestamp metadata and hex inspection.

Headless Doctor

Generate a redacted support/readiness report.

Offline simulator + fault injection

Exercise the same data pipeline without hardware, plus injectable faults for negative testing.

GM runtime tuning

Change clock quality and BMCA priorities live via pmc — no engine restart.

Wireshark & engineering reports

One click into Wireshark (live or replay) plus redacted JSON/Markdown engineering reports.

Quick start

# from the latest release: gPTP-Studio-<ver>-linux-x64.tar.gz
tar -xzf gPTP-Studio-*-linux-x64.tar.gz
cd gptp-studio-distributed
./bin/gptp-studio --doctor
./bin/gptp-studio

Validated on Ubuntu 22.04 / 24.04 LTS. The tarball is self-contained.
